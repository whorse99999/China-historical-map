# 史料及测绘来源

- [日本国立国会图书馆 1975 年书目](https://ndlsearch.ndl.go.jp/books/R100000002-Ia0000013114)与[1982 年书目](https://ndlsearch.ndl.go.jp/books/R100000002-Ia0000046525)分别记中华地图学社、地图出版社出版的第2册。可确认出版信息，尚不能锁定本 JPG 版次。
- [出版社公开总编例](https://detail.youzan.com/show/goods?alias=26vhk0otenyep&from_source=gbox_seo)说明全图可反映一个或多个年代。[公开文件目录](https://nayona.cn/1848631.html)列有秦时期图组编例和秦全图，仅作为检索线索。
- [《史记·蒙恬列传》](https://www.shidianguji.com/book/SK0698/chapter/1l9z609cpddt6)、[《史记·匈奴列传》影印](https://upload.wikimedia.org/wikipedia/commons/9/92/NLC892-411999012543-925_%E4%BA%8C%E5%8D%81%E4%B8%80%E5%8F%B2_%E7%AC%AC18%E5%86%8A.pdf)、[《资治通鉴》卷七](https://zh.wikisource.org/zh-hans/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7007)用于核查渡河、据守、设防及事件次序。
- [河套地区全新世黄河古河道的分布及期次划分](https://pubs.cstam.org.cn/article/id/dzlxxb_0c8c5abe-00ed-4ee6-9e95-a4394db67960)。原始研究使用遥感、1∶5万调查、钻孔剖面、光释光及碳十四测年。可核查古河道时段与分布。
- [乌拉特前旗政府关于小佘太秦汉长城保护项目的答复](https://www.wltqq.gov.cn/zfxxgk/fdzdgknrwltqq/jyta/rdjytawltqq/202512/t20251211_217600.html)提供实存设施及点段名称。
- [宁夏文物考古研究所刊载的九原考察资料](https://www.nxkg.org.cn/silukaogu/470.html)的公开索引列有麻池古城墙体交点、经纬度与标称误差，并讨论孟家梁古城。正文打开超时，测绘基准和误差定义未获独立核实。[包头市政府答复](https://baotou.gov.cn/zfxxgk/fdzdgknr/fd_jyta/qxqzf/jyqrmzf/zxta/202505/t20250529_526608.html)提供麻池作为秦直道北端的认定。[实地考察与图集定位比较](https://www.whb.cn/zhuzhan/xueren/20190510/261553.html)指出图集所取九原郡治为孟家梁。
- [中国地图出版社集团](https://www.sinomaps.com/)为版次和权限询证入口。[国家版权局公布的著作权法修改决定](https://www.ncac.gov.cn/xxfb/ywxx/202011/t20201112_47358.html)为法规参考，未提供本图版授权。
